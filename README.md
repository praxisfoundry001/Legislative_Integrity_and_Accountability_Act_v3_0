# Legislative Integrity and Accountability Act

**Open-Source Model Legislation for Preventing Congressional Financial Conflicts and Protecting Public Trust**

**Version:** v3.0

**Current DOI:** https://doi.org/10.5281/zenodo.23548178

**Previous published version:** https://doi.org/10.5281/zenodo.22693996

## Overview

The Legislative Integrity and Accountability Act (LIAA) proposes a federal framework for preventing financial conflicts of interest involving Members of Congress, senior congressional staff, and covered household persons.

The proposal addresses concentrated financial exposure, divestiture, public accountability, administrative enforcement, judicial review, and periodic evaluation while preserving ordinary diversified investment and constitutionally protected legislative functions.

This is proposed model legislation, not enacted federal law.
